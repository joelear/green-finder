# Proposed Domains

- **Plant Matcher (dom.plant-matcher)** — Enables users to find and explore plants matched to their home environment via a quiz-driven interface. Pages: `/`, `/quiz`, `/results`, and fallback `/*`.

See `features_catalogue.json` for assignments and confidence scores. No backend or entities present as this is a frontend-only app.

## Review me

This app currently has a single top-level domain due to absence of backend endpoints or multiple bounded contexts. Pages are seeded from React Router routes found in `src/pages`. If additional backend or complex module separation appears, please advise for domain splitting.
